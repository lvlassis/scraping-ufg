# BUG-001 - Sigaa-Scraper - Erro ao fazer scraping de Avaliações
21/09/2026
## Descrição
Ao tentar listar as atividades, o scraper não está conseguindo identificar que uma **atividade** é uma **avaliação**, então a atividade sai **sem nome**, **sem data**.

## Componentes Afetados
- [[Scraper do Sigaa]]
